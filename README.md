# Mercado Libro

Full-stack book marketplace web application built with a Java REST API backend and an Angular frontend.

Mercado Libro allows users to publish books, browse available publications, filter and sort results, manage favorites, update book conditions, and use account-related flows such as authentication, email verification, and password recovery.

## Tech Stack

### Backend

- Java
- REST API
- JPA / Hibernate
- JWT authentication
- Maven

### Frontend

- Angular
- TypeScript
- HTML
- CSS
- Internationalization: English and Spanish

## Features

- User registration and login
- Email verification
- Password recovery and password reset
- JWT-based authentication with access and refresh tokens
- Book publication management
- Favorite publications
- User-specific publications
- Book condition updates
- Filtering, sorting, and pagination
- Location-based publication filtering
- English and Spanish internationalization
- Validation and error handling
- Frontend/backend deployment configuration
